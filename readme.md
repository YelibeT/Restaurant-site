# 🍽️ Restaurant Website

A full-stack restaurant website built to provide visitors with an easy way to explore a restaurant's menu and order through a web interface.

## 🌐 Live Demo

[View Live Website](https://restaurant-site-topaz.vercel.app/)

## 🛠️ Tech Stack

**Frontend**
- React
- JavaScript
- CSS

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB
- Mongoose

**Deployment**
- Vercel for the frontend
- MongoDB Atlas for cloud database hosting

## ✨ Features

- Responsive restaurant website interface
- Restaurant content and menu presentation
- Frontend and backend application structure
- Database integration using MongoDB

## 📁 Project Structure

```text
Restaurant-site/
├── react-app/    # React frontend
└── Backend/      # Node.js and Express backend
```

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js and npm
- MongoDB database or a MongoDB Atlas connection

### 1. Clone the Repository

```bash
git clone https://github.com/YelibeT/Restaurant-site.git
cd Restaurant-site
```

### 2. Set Up the Frontend

```bash
cd react-app
npm install
npm run dev
```

### 3. Set Up the Backend

Open a separate terminal:

```bash
cd Backend
npm install
```

Create a `.env` file in the backend directory and configure the required environment variables:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
```

Start the backend using the script defined in `Backend/package.json`.

This project provides practical experience in building a web application with React, developing server-side functionality with Node.js, and connecting an application to a MongoDB database.
